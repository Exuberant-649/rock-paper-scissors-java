# Rock Paper Scissors (Java) 🎮

A simple console-based **Rock-Paper-Scissors** game written in Java.

---

## Features 🧠
- Play multiple rounds
- Random computer choices
- Simple and fun console interface
- Quit anytime you like

---

## How to Run 🖥️

1. **Clone** the repository  
   ```bash
   git clone https://github.com/YOUR-USERNAME/rock-paper-scissors-java.git
   cd rock-paper-scissors-java
2. Compile the code

   javac src/samplepackage1/RockPaperScissors.java


3. Run the program

   java -cp src samplepackage1.RockPaperScissors
